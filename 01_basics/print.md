# print()

## 📘 Explanation
print() displays output to the screen.
It helps debug and show results.

You can print:
- Text
- Numbers
- Variables
- Expressions

## 🧠 Concepts
- Printing multiple values
- Using separators
- Formatting output

## 🎯 Why Important
Every program needs output.
Debugging without print is hard for beginners.
